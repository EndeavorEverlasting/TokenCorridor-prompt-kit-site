# Moonwake — public first release (PS-0208)

Public interface path: `/moonwake/` (also deployed at `/` when GitHub Pages uses this repository's Actions publication pipeline).

- Source is the private TokenCorridor/Moonwake repository, immutable ID `1382415392`; only reviewed static files are mirrored here.
- The Prompt Library remains the existing public, generated catalog under `/prompt-library/`. No private prompt database, local execution receipts, workstation identity, OAuth credentials or live work feed is published.
- Approved R3 vector and photographic assets are byte-for-byte identical to the owned PR #283 source, with Git blob SHAs checked during publication.
- Fonts retain the original private layout's Syne/Literata; license text is bundled with each typeface under `/moonwake/assets/fonts/`.
- The experience offers Night Observatory, Tidal Light, and system preference with a locally stored selection.
- The host-only Observatory remains a separate authenticated/local feature, not a public data source.
- Production verification requires a successful GitHub Pages deployment **and** an HTTP/browser readback; a Git commit alone is not proof of a live site.

Canonical public release manifest: `moonwake/release-manifest.v1.json`.
